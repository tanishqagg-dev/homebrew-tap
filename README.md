# tanishqagg-dev/homebrew-tap

Homebrew casks for [wassup](https://github.com/tanishqagg-dev/wassup), WhatsApp from your terminal and your AI apps.

```bash
brew tap tanishqagg-dev/tap
brew trust tanishqagg-dev/tap   # Homebrew asks you to trust a third-party tap once
brew install wassup
wassup setup
```
